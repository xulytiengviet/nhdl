01 / BILASCRIPT FRONTEND → NHDL → VHDL-2008

Nguồn BilaScript bên trái.
VHDL sinh ra bên phải.

BilaScript v4 là frontend dựa trên CVNSS4.0. Compiler NHDL tái sử dụng lexer/parser, kiểm tra kiểu và sinh VHDL-2008 dùng nhdl_ternary. Profile tổ hợp: 1–3 đầu vào trit. Profile clocked: một tham số trạng thái, reset về O, enable giữ/chạy. Hỗ trợ +, −, × và các cổng NHDL; từ chối vòng lặp, I/O, số ngoài miền và cấu trúc chưa hỗ trợ.

+ và − trả một trit modulo cân bằng 3, không giữ carry. Tên cổng được ánh xạ thành p0/p1/p2; tên gốc vẫn có trong hồ sơ. Source map ánh xạ khai báo và câu trả về, không ánh xạ từng ký tự.
Chạy cổng kiểm chứng
node nhdl/tools/nhdlc.mjs input.bila --out nhdl/build/generated --verify
CLI biên dịch lại từ nguồn, chạy GHDL analyze → elaborate → testbench → synthesis. Báo cáo verification.json gắn SHA-256 của nguồn, VHDL và testbench. Trình duyệt chỉ sinh mã: NOT_RUN, không tự báo PASS GHDL.

NEUTRAL HARDWARE DESCRIPTION LANGUAGE / 0.5

BilaScript là frontend; VHDL-2008 + nhdl_ternary là backend. Mục tiêu: mô phỏng giảng dạy, nghiên cứu và thử nghiệm. Tên kiến trúc tùy chọn: Nexus.
Bộ đếm tam phân có trạng thái
---bila:strict---
// @nhdl clocked reset=O
haml_sob dem(q: trit): trit {
  trov_ved inc(q);
}
Cạnh lên clock: reset ưu tiên → O; enable bật → trạng thái kế tiếp; enable tắt → giữ. Chuỗi O → P → N → O. Chọn ví dụ “Bộ đếm” trong Studio để xem VHDL thật.
