LIVE MODEL
Bảng chân lý · 27 tổ hợp hợp lệ
ABCiSCo

VHDL-2008 / full adder

use work.nhdl_ternary.all;

-- Hai trit duong: 1 + 1 = 2
process(all)
  variable r : add_result;
begin
  r := full_add(a, b, ci);
  s  <= r.s;
  co <= r.carry;
end process;

-- s = N, co = P
-- (-1) + 3 * (+1) = 2

04 / HỆ SINH THÁI TIẾNG VIỆT

Từ biểu đạt tiếng Việt
đến mô hình phần cứng.

Mỗi lớp có trách nhiệm riêng. Các kết nối dưới đây là hợp đồng thiết kế, chưa phải một pipeline tích hợp hoàn chỉnh.

01

CVNSS4.0

Lớp biểu diễn tiếng Việt. Adapter cần bảng ký hiệu có phiên bản và cơ chế lưu ứng viên giải mã.

Đa nghĩa ≠ round-trip nguyên văn
02

BilaScript

Frontend dự kiến xuất VHDL cùng source map, kiểm tra kiểu và thông báo tiếng Việt.

Chưa tích hợp compiler
03

TinyLLM / TinyBila

Định hướng trợ lý sinh mã, testbench và điều phối. Mã sinh cần vượt bộ kiểm chứng.

Chưa nối model / runtime
